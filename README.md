# ANTIGRAVITY // Zero-G Vector Protocol

An interactive, high-precision physics simulation and arcade survival game built directly by **Antigravity**.

---

## 🚀 Features

- **Dynamic Zero-G Newtonian Physics**: Momentum, rotational inertia, space drag, boundary deflection.
- **Gravitational Singularity Fields**: Procedural black hole anomalies pulling vessels and debris via inverse-square law gravitation.
- **100% Procedural Synthesizer (Web Audio API)**:
  - Dynamic white/pink-noise engine thruster hums with resonant filter cutoff modulation.
  - Sub-bass saw oscillator hum.
  - Multi-tone pentatonic harmonic chimes with pitch-shifting combo multipliers for core pickups.
  - Explosive repulsor shockwave resonant frequency drops.
- **Particle & VFX System**: Exhaust trails, dual nozzle thruster ports, deflection sparks, shockwave rings, and screen shake.
- **Glassmorphic Cyberpunk HUD**: Real-time G-load, velocity (km/s), hull integrity gauge, repulsor capacitor, overdrive boost gauge, and rotating mini radar.

---

## 🎮 Flight Controls

| Control | Action |
| :--- | :--- |
| **`W` / `▲` / Left Click** | Main Thrusters (Vector Propulsion) |
| **`A` / `D` / `◄` / `►`** | Pitch / Attitude Yaw Rotation |
| **`Shift`** | Overdrive Boost (Consumes Boost Fuel) |
| **`Space` / Right Click** | Gravitational Repulsor Pulse (Deflects Nearby Debris) |
| **`M`** | Mute / Unmute Audio Synthesizer |

## 🛠️ Tech Stack

- **HTML5 Canvas 2D API** with Retina / High-DPI hardware acceleration
- **Native Web Audio API** (Zero external audio assets or network requests)
- **Vanilla Modern JavaScript (ES6+)** with 60 FPS `requestAnimationFrame` loop
- **Modern CSS3 Glassmorphism** with backdrop filters and responsive viewports
